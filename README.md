# 🔌 Заявки на услуги электрика (Вика)

Этот репозиторий используется как CRM-система на базе **GitHub Projects** для учета заказов, расчета смет и планирования выездов.

## 📋 Текущие статусы (Колонки на доске)

1. **📩 Новая заявка** — Поступил звонок или сообщение, данные клиента внесены.
2. **💬 Оценка** — Вика связалась с клиентом, уточнила детали, отправила расчет.
3. **✅ Согласовано** — Клиент подтвердил дату, время и стоимость.
4. **🔧 В работе** — Электрик на объекте.
5. **📦 Ожидают запчасти** — Нужна закупка материалов, визит перенесен.
6. **🏁 Выполнено** — Работа сдана, оплата получена.
7. **🗑️ Архив / Отказ** — Клиент передумал, недоступен или заказ не состоялся.

2. Откройте доску **Заявки Вики**.
